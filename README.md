# Amazon-Food-Review-Sentiment-Analysis
Machine learning and deep learning project analyzing sentiment in Amazon Food reviews.

## Project Overview
This project uses Amazon food reviews to predict if a customer review is positive or negative. I used machine learning and deep learning models to compare their performance and see which model worked best for sentiment analysis.

## Tools Used
- Python
- Google Colab
- Pandas
- Scikit-learn
- TensorFlow / Keras
- Matplotlib
- Kagglehub
  
  ## Project Steps
  - Loaded the Amazon Food Reviews dataset
  - Explored and cleaned the data
  - Converted review scores into positive and negative sentiment
  - Prepared the review text for machine learning
  - Trained and compared machine learning models
  - Built a deep learning model
  - Compared the model results
 
    ## Models Used
    - Logistic Regression
    - Decision Tree
    - Random Forest
    - Support Vector Classifier (SVC)
    - Deep Learning Neural Network
   
  ## What I Learned
This project helped me better understand how machine learning can be used to analyze text and predict sentiment. I also gained experience comparing different models and seeing how their performance can change based on the data.
